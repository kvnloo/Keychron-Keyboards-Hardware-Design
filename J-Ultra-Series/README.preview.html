J Ultra Series - Hardware Design Files

Ultra-slim J-series wireless keyboards with 8K polling, ZMK firmware, and Keychron Launcher support.

Part of the Keychron Keyboards Hardware Design repository.

Available Models

Model Layout Components Firmware
J6 Ultra 8K 100% Plate, PCB, Top Case, Bottom Case, Full Model ZMK
J9 Ultra 8K 75% Plate, PCB, Top Case, Bottom Case, Full Model ZMK
J11 Ultra 8K 96% Plate, PCB, Top Case, Bottom Case, Full Model ZMK

Repository Contents

This series folder currently includes J6 Ultra, J9 Ultra, and J11 Ultra model folders with stp, dwg, and pdf hardware design files.

# J Ultra Series - Hardware Design Files

> Ultra-slim J-series wireless keyboards with 8K polling, ZMK firmware, and Keychron Launcher support.

Part of the [Keychron Keyboards Hardware Design](https://github.com/Keychron/Keychron-Keyboards-Hardware-Design) repository.

## Available Models

| Model | Layout | Components | Firmware |
|---|---|---|---|
| [J6 Ultra 8K](<./J6 Ultra/README.md>) | 100% | Plate, PCB, Top Case, Bottom Case, Full Model | ZMK |
| [J9 Ultra 8K](<./J9 Ultra/README.md>) | 75% | Plate, PCB, Top Case, Bottom Case, Full Model | ZMK |
| [J11 Ultra 8K](<./J11 Ultra/README.md>) | 96% | Plate, PCB, Top Case, Bottom Case, Full Model | ZMK |

## Repository Contents

This series folder currently includes J6 Ultra, J9 Ultra, and J11 Ultra model folders with `stp`, `dwg`, and `pdf` hardware design files.

## Opening the Files

| Format | Free Software | Commercial Software |
|---|---|---|
| `.stp` | FreeCAD, Onshape | Fusion 360, SolidWorks |
| `.dwg` | LibreCAD (limited), QCAD | AutoCAD, DraftSight |
| `.pdf` | Any PDF viewer | - |

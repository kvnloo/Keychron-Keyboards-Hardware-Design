# Orca Series - Hardware Design Files

> Compact split ergonomic keyboard files with an integrated trackball, vertical scrolling controls, portable magnetic storage, and deep keymap customization.

Part of the [Keychron Keyboards Hardware Design](https://github.com/Keychron/Keychron-Keyboards-Hardware-Design) repository.

## Available Models

| Model | Layout | Integrated Controls | Firmware | Status |
|---|---|---|---|---|
| [Orca Echo](./Orca/README.md) | Compact split ergonomic | Trackball, touchpads, and left thumb wheel | ZMK | Files published |

## Repository Contents

This series folder currently includes the Orca Echo model folder with published `stp`, `dwg`, and `pdf` downloads hosted on Keychron's official server.

## Download Files

| File | Description | Format |
|---|---|---|
| [Orca Echo files](./Orca/README.md#downloads) | Left and right top cases, bottom cases, PCB, plates, and full-model hardware files | STP / DWG / PDF |

## Opening the Files

| Format | Free Software | Commercial Software |
|---|---|---|
| `.stp` | FreeCAD, Onshape | Fusion 360, SolidWorks |
| `.dwg` | LibreCAD (limited), QCAD | AutoCAD, DraftSight |
| `.pdf` | Any PDF viewer | - |
